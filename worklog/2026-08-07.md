# Work Log · August 7, 2026 (Friday)

**Hours:** ~4.5

## Overview

First tool of Wave 4, the color batch: a HEX / RGB / HSL converter. It opens a new **Color**
category — the second new category of Phase 3 — which deliberately widens the audience beyond
developers toward designers and anyone picking colors for a page.

## Today's Work

### 1. One Canonical Color, Many Views

The design mirrors the base converter from a couple of weeks ago: keep a single source of
truth — an RGB triple — and render every other representation from it. Edit any format (HEX
text, the R/G/B fields, the H/S/L fields) or drag the native color picker, and everything else
updates, with a live swatch preview. The one wrinkle is the HEX field: like the base
converter, it keeps the raw text you're typing so a half-entered value isn't reformatted
mid-keystroke, while every other control writes back a clean hex string.

### 2. The Conversions — and Verifying Them

The actual work is three conversions: HEX ↔ RGB (plus short `#rgb` form), and RGB ↔ HSL. HSL
is the fiddly one — the hue calculation branches on which channel is the maximum, and the
back-conversion uses the standard hue-to-RGB helper. Color math is easy to get *almost* right,
so I tested it before building the UI:

- The three primaries land exactly where they should: red → hsl(0, 100%, 50%), green → 120°,
  blue → 240°, and any gray → 0% saturation.
- Short hex `#f0a` expands to `#ff00aa`, hex without a `#` still parses, and junk returns null.
- HSL → RGB round-trips a batch of real colors with a maximum per-channel error of **2** out
  of 255 — the unavoidable cost of rounding through integer HSL, and small enough to be
  invisible.

### 3. The Category System Paid Off Again

Adding a whole new category was almost nothing: one entry in the `CategoryKey` type, one
`color` label in each message file, and tagging the tool. Everything else — the category page
at `/c/color`, the home overview card, the navbar dropdown, the sitemap entry, and search —
picked it up automatically, in both languages, because they all derive from the registry. I
verified `/en/c/color` and `/zh/c/color` render, the sitemap gained the new entries, and the
home overview shows a Color card. This is the third time the "registry as pure structure"
decision from the i18n work has made growth free; it keeps proving itself.

### 4. Verification

Unit-tested the conversions (primaries, gray, short/no-hash/invalid hex, HSL round-trips),
lint + build (63 static pages now), and served both locales — translated labels, no English
leaking into the Chinese page, and the new category correctly wired through category page,
home, sitemap, `/tools`, and search.

## Outcome

Wave 4 is underway and the Color category exists — twenty tools now across eight categories.
The satisfying part wasn't the color math (though getting HSL exactly right felt good) but
watching an entire new top-level category slot into the navigation, sitemap and search for
the cost of three tiny edits. That's the payoff of the mid-phase restructure compounding.
