## Learning Notes

- REM conversion is simple arithmetic, but the root font size is part of the input and must be
  explicit; assuming 16px would silently produce wrong results for customized designs.
- Formatting converted decimals requires a deliberate precision boundary so binary floating-point
  noise is hidden without filling ordinary CSS values with trailing zeroes.
- Keeping batch input to one number per line makes error locations and blank-line preservation
  predictable without turning this focused calculator into a CSS parser.
