## Learning Notes

- Browser URL normalization can lowercase hosts, remove default ports and resolve dot segments.
- A base ending with a slash resolves a child differently from a base ending with a filename.
- Query pairs must be retained as ordered pairs, not collapsed into an object, to preserve
  repeated keys and avoid special-key handling such as `__proto__`.
- Native query decoding interprets `+` as a space; `%2B` stays a literal plus and percent
  encoding is decoded once. Paths and fragments follow different representation rules.
- The roadmap records learning topics and daily allocations, not a timer-derived owner work duration.
