## Learning Notes

- A finite JavaScript number is not necessarily a safe integer. Finiteness alone is insufficient
  when inferring types for long IDs.
- String preservation is a conservative fallback that retains source digits without adding
  a big-number dependency or changing JSON's supported value types.
- Precision guarantees need a clear scope: CSV type inference and native JSON parsing are
  distinct entry points.
