## Learning Notes

- Multi-layer shadows are a comma-separated CSS list, so each layer can be modeled independently
  and composed only at the output boundary.
- Selecting one layer for editing keeps a multi-layer control surface compact while still making
  the order and active layer explicit.
- Using one generated value for both inline preview styling and copied CSS prevents the visual
  result from drifting away from what the user receives.
