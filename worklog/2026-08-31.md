## Today's Work

### 1. Percentage Calculator

Built `/percentage-calculator` around the three questions people most commonly ask: finding a
percentage of a number, finding what percentage one number is of another, and calculating the
percentage change between a starting and final value. Each mode changes the field labels so the
user does not have to infer where each number belongs.

Zero denominators are handled explicitly. A part cannot be expressed as a percentage of a zero
whole, and percentage change from zero has no finite result, so the page displays an invalid-input
message instead of leaking `Infinity` into the interface. The result updates live and can be copied.

### 2. BMI Calculator

Built `/bmi-calculator` with metric and US/imperial measurement modes. It uses kilograms divided
by metres squared for metric values and the customary pounds/inches formula with the factor 703.
Switching modes converts the measurements already entered rather than making the user start over.

The result is classified into the standard adult screening ranges: underweight, healthy weight,
overweight and obesity. The page also clearly states that BMI is a general screening measure, not
a medical diagnosis, and does not account for age, pregnancy, muscle mass or individual history.

### 3. Shared Logic and Tests

Added `lib/everyday-calculators.ts` so the formulas and number formatting stay separate from React.
The six new tests cover percentage calculations, increasing and decreasing changes, zero handling,
metric and imperial BMI, exact BMI category boundaries and floating-point formatting.

The first test run highlighted the small expected difference caused by the rounded imperial factor
of 703. The test was corrected to verify the customary imperial result directly instead of
demanding false precision against the metric formula.

### 4. Bilingual Integration and Browser QA

Added English and Chinese copy for both pages, including tool descriptions and health guidance.
Registered both tools so they appear automatically in search, the Calculators category, the full
tool listing and the bilingual sitemap. Each route also has localized metadata and JSON-LD.

Browser testing verified percentage change from 80 to 100 as 25%. It also caught a subtle BMI unit
switch issue: rounding converted measurements to one decimal made 22.9 briefly display as 22.8.
Keeping three decimals for converted inputs fixed the jump. The second browser run confirmed a
stable 22.9 result in both systems, no console errors and a clean narrow-screen layout.

Final checks: 72 tests passing, lint clean and a successful production build with 99 static pages.
