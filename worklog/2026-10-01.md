## Learning Notes

- JSON Pointer is a path representation, not an expression language. Keeping the feature to
  standard pointers makes copied paths predictable and avoids evaluating arbitrary input.
- Recursive tree rendering needs separate state for expansion and selection. During a search,
  automatically exposing ancestor paths keeps matches understandable without destroying the
  user's normal expansion state.
- The document root has a valid empty JSON Pointer, so shared copy controls need to distinguish a
  meaningful empty value from a missing output.
