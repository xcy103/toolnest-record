## Learning Notes

- Parser APIs may return no documents for comments-only input; guard that state separately
  from syntax errors.
- YAML can represent values that JSON cannot. Explicit rejection preserves the distinction
  between an unsupported number and a legitimate null.
- A JSON replacer validates nested values at serialization time without adding a second
  handwritten YAML parser.
