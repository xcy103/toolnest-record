  character. Configured decoding to retain it as part of the user's text.
- Extracted the existing UTF-8 conversion routines into a shared, testable helper.
- Added three regression tests covering known whitespace encodings, Unicode/BOM
  round trips, pasted Base64 whitespace and malformed Base64/UTF-8 rejection.

## Learning Notes

- Whitespace can be meaningful plain text even when it is ignored in encoded input.
  Empty-input checks should reflect the current conversion direction.
- TextDecoder's ignoreBOM option means bypassing special BOM processing, thereby
  retaining the leading character in the decoded text.
- Fatal UTF-8 decoding remains enabled so invalid bytes do not silently become
  replacement characters. This remains a text converter rather than a binary-file tool.
