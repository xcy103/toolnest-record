## Completed Work

Added `/random-picker` to draw one or more entries from a pasted line-based list. The tool ignores
blank lines and trims each entry. Users can remove exact duplicate entries and choose whether
draws happen without replacement. The UI shows both the input count and eligible pool count,
validates a whole-number draw size from 1 to 100, and prevents an oversized draw without
replacement.

Each draw replaces the displayed result and increments a visible draw number; results can be
copied. Random selection uses `crypto.getRandomValues` with rejection sampling for uniform indices.
Without-replacement selection uses a partial shuffle so no candidate position is chosen twice in
one draw. English and Chinese UI, metadata, structured data, Generator-category registration,
search and sitemap coverage were added.

## Learning Notes

Using a random 32-bit value directly modulo the candidate count can slightly bias some indices.
Rejection sampling discards values outside the largest evenly divisible range. Separating the
eligible pool from the input count also makes the effect of duplicate removal visible before a
draw.
