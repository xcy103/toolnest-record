## Learning Notes

- CSS radius shorthand follows clockwise order and expands differently for one, two, three and
  four values. Compression must preserve those relationships.
- Percentage radii depend on the element's width and height, so a rectangular preview shows their
  effect more clearly than a square.
- Linked controls need an explicit synchronization rule when independent values already differ.
