- Added three regression tests covering signed/nested overflow, finite numeric
  boundaries and quoted-text round trips at both indentation settings.

## Learning Notes

- JSON numeric syntax can be valid while its parsed JavaScript value is nonfinite.
  Syntax validation alone cannot guarantee a faithful numeric conversion.
- A reviver checks nested values during parsing without a separate tree traversal.
- Quoting a number preserves its source text when its value is outside the
  supported numeric range. Ordinary floating-point rounding, underflow and unsafe
  integer precision remain unchanged by this maintenance.
