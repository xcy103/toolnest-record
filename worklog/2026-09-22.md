## Completed Work

Added `/list-comparison` to compare two line-based lists. The tool shows entries in both lists,
left-only entries, right-only entries and a combined unique list. Each result shows its item count
and can be copied. Case sensitivity and trimming surrounding whitespace can be changed without
re-entering the lists.

The comparison uses the existing line-splitting and normalization rules. It ignores blank lines,
keeps the first occurrence on each side and preserves input order. Shared entries and the combined
list keep the left side's original text; right-only entries keep the right side's original text.
English and Chinese UI, metadata, structured data, Text-category registration, search and sitemap
coverage were added.

## Learning Notes

List comparison needs an explicit policy for duplicates and spelling. Normalizing only the match
key, while keeping the first original line for display, makes case-insensitive matches predictable
without silently changing the user's text.
