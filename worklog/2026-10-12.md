## Learning Notes

- Valid finite inputs do not guarantee finite division results. Validate the result separately
  before formatting or allowing it to be copied.
- Native JSON parsing can produce Infinity from an overflowing exponent, and JSON.stringify
  serializes nonfinite numbers as null. Tools must reject that state explicitly to avoid
  silently changing numeric data into a different JSON type.
- Regression tests should cover error recovery, preserved output boundaries and batch line
  information, not only the initial failure.
