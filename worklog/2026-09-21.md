## Completed Work

Added `/csv-viewer` to open a local CSV file or accept pasted CSV and display it as a readable
table. The viewer supports comma, semicolon and tab delimiters, an optional header row, column-name
search, filtering across every cell, and stable ascending or descending sorting from each header.
Large results are paginated at 100 rows per page, while wide tables scroll inside their own area
instead of widening the page.

The tool reuses ToolNest's RFC 4180 parser, including quoted delimiters, doubled quotes, embedded
line breaks and clear malformed-row errors. Browser-side limits are 2 MB, 5,000 data rows and 100
columns. Files are read entirely in the browser and are not uploaded. English and Chinese UI,
metadata, JSON-LD, Developer-category registration, search and sitemap coverage were added.

## Learning Notes

A practical browser-side table viewer needs two different limits: parsing limits protect memory and
pagination protects rendering. Keeping those concerns separate allows the tool to accept useful
files without inserting thousands of table rows into the DOM at once. Stable sorting also matters
because equal values should not jump into an arbitrary order after each click.
