## Completed Work

  opposite-sign values overflowed: -1e308 to 1e308 should yield 200%, but the
  helper returned Infinity and the page displayed its invalid-input message.
- Added a divide-first fallback when both inputs are finite but their difference
  is nonfinite. The original difference-based calculation remains for ordinary
  values, retaining accuracy for small changes between nearby numbers.
- Preserved zero-baseline rejection, negative-baseline semantics and the existing
  formatting behavior for genuinely nonfinite results.
- Added two regression tests covering signed large values through Number.MAX_VALUE,
  asymmetric changes, small deltas, negative baselines, zero and invalid results.
