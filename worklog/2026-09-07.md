## Catch-Up Work

### 1. Exact Crop Controls

Added `/image-crop` for PNG, JPEG and WebP sources. Users can enter integer left, top, width and
height values, or start from centered Free, 1:1, 4:3 and 16:9 presets. Validation requires the
selection to stay inside the source image and within the existing canvas pixel budget.

The live canvas preview dims the excluded area and redraws the selected source pixels at full
brightness. It updates immediately when coordinates or aspect presets change.

### 2. Local Export and State Safety

The selected pixels are drawn to a separate output canvas and can be exported as PNG, JPEG or
WebP. Lossy formats include a quality control, and JPEG supports a background colour for sources
with transparency. Downloads use the source basename plus `-cropped` and the verified format
extension.

The page enforces the shared 20 MB, 8192-pixel-side and 16,777,216-pixel limits. Request tokens
stop slower image reads or exports from replacing newer choices. Object URLs and canvas memory
are released when results change or the page closes.

### 3. Integration and Verification

The tool is registered in the Image category with English and Chinese UI, metadata, JSON-LD and
sitemap routes. A generated 120 × 80 four-colour PNG was loaded in the browser; selecting the
60 × 40 upper-right quadrant produced a 60 × 40 green PNG, matching the source pixels.
