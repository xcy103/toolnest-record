# Work Log · August 12, 2026 (Wednesday)

**Hours:** ~4.5

## Overview

A lighter one after the unit converter: a lorem ipsum placeholder-text generator. Choose an
amount and a unit (paragraphs, sentences or words), optionally start with the classic "Lorem
ipsum dolor sit amet…" opening, and copy the result. Simple, but it reused a pattern I've now
internalized.

## Today's Work

### 1. Generation

A pool of the standard lorem words, and three builders: a word (random pick), a sentence
(6–14 words, capitalized, a comma dropped mid-way for rhythm, ending in a period), and a
paragraph (3–6 sentences). The "start with Lorem ipsum" option splices the canonical opening
in front, replacing whatever random first sentence was generated so it reads right.

### 2. The Now-Reflexive SSR Guard

This is the fourth tool whose output is random (after the password and UUID generators, and
in spirit the clocks), and the rule is now automatic: **anything random or time-based must be
generated on the client only.** If I generated the text during render, the server would
produce one random paragraph and the browser another, and React would throw a hydration
mismatch. So the output starts empty and is filled in a mount effect (state updates wrapped in
a named function inside the effect, per the lint rule). Regeneration on option-change and via
the button run the same client-side path.

It's worth noting how much faster these tools go now that the cross-cutting concerns —
client-only randomness, the message-catalogue split, the verify-both-locales checklist — are
reflexes rather than things I rediscover each time.

### 3. Verification

Lint + build (71 static pages) and both locales served: translated amount/unit/checkbox
labels, no English leaking into the Chinese page, and the Text category now holds four tools
(counter, case converter, diff, lorem) with the generator on `/tools`.

## Outcome

A quick, useful addition that padded out the Text category. The takeaway is meta: the value of
