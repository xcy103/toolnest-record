## Completed Work

### 1. PNG, JPEG and WebP Conversion

Added `/image-converter` using the same image-reading and exporting component as the resizer.
Conversion preserves the original pixel dimensions. PNG export preserves transparency; JPEG and
WebP expose quality controls. JPEG fills the canvas with a user-selected background before drawing
the image because the JPEG format cannot retain transparency.

The exporter checks the returned Blob MIME type against the selected output format. If a browser
falls back to another encoder, the tool reports an export error instead of offering a mislabeled
download. PNG, JPEG and WebP extensions are generated from the selected, verified output type.

### 2. Product Scope and States

Supported inputs are PNG, JPEG and WebP with the same file and pixel limits as the resizer.
The page states that the output is a still image and does not preserve source animation or metadata.
No new dependency, server upload or persistent browser storage was added. Loading, processing,
decoding errors and missing-result states are translated into English and Chinese.
