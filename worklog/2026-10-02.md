## Learning Notes

- A JSON string literal includes its surrounding double quotes. Returning a complete literal
  makes the output directly usable in JSON instead of exposing an ambiguous escape fragment.
- JSON parsing accepts many value types, so syntax validation alone is insufficient; the parsed
  value must also be checked to ensure it is a string.
- Empty output can be a successful conversion result. UI state must distinguish that case from
  having no result or an invalid input.
