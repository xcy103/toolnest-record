## Learning Notes

- User-provided column names must be treated as data, even when they match JavaScript
  prototype-related property names.
- Assigning __proto__ to a plain object is not equivalent to creating an own data property.
- Missing data must be distinguished from inherited properties; Object.hasOwn makes that
  distinction explicit without discarding legitimate user-provided fields.
